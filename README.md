# Ultimate PMOD Port

Port of the StepMania 5.2 theme **Ultimate** to **PMOD** (the Pump It Up focused StepMania fork).

## Repository Layout

- `ultimate-master/` — working folder. All port changes happen here.
- `_sm5.2themes/ultimate-master/` — known-good SM5.2 reference (read-only, gitignored).
- `_fallback/` — PMOD fallback reference (read-only, gitignored).
- `pmod/` — PMOD default theme reference (read-only, gitignored).

## Project Files

- [AI.md](AI.md) — how the AI assistant should work in this project.
- [portguidelines.md](portguidelines.md) — proven steps for porting SM5.2 themes to PMOD.
- [potentialissues.md](potentialissues.md) — port risks and the running log of fixes applied.
- [roadmap](roadmap) — current and next version's pending items.
- [versionlog](versionlog) — completed version history (created when items roll over).
